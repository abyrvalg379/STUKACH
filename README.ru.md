# STUKACH

![STUKACH](screenshots/stukach_cover.png)

Пайплайн-валидатор ассетов для Blender.

*English documentation: [README.md](README.md)*

**Blender 5.2 · v1.7.2 · Автор: Maksim Kovalev**

---

## Установка

Скачайте `STUKACH.zip` со страницы [последнего релиза](https://github.com/abyrvalg379/STUKACH/releases/latest).

**Вариант 1 — Drag & Drop:**
Перетащите `STUKACH.zip` во вьюпорт Blender.

**Вариант 2 — Меню:**
Edit → Preferences → Get Extensions → ⚙️ → Install from Disk → выберите `STUKACH.zip`

**Вариант 3 — Вручную:**
Скопируйте папку `STUKACH` в `scripts/addons/`, затем включите аддон в Preferences → Add-ons.

Вкладка **STUKACH** появится в N-панели (View3D и UV Editor).

---

## Быстрый старт

1. Откройте вкладку **STUKACH** в N-панели
2. Нажмите **▶ RUN STUKACH**
3. Выделите объекты во вьюпорте или используйте кнопки скоупа **Scene** / **Collection**
4. Включите чекеры — статусные точки покажут результат (зелёная ✓ / жёлтая / красная)
5. Кнопка **Sel** выделяет проблемные элементы в Edit Mode

## Категории проверок

42 проверки в 7 категориях плюс сценовая проверка **Scene Units** (без чекбокса в сетке). **Валидатор иерархии** — отдельная подсистема со своим Scan: 13 правил (5 ERROR + 8 WARNING), здесь не считается.

### TOPOLOGY
| Проверка | Критичность | Описание |
|---|---|---|
| Non Manifold | BLOCKER | Рёбра, принадлежащие более чем двум граням |
| Boundary Edges | INFO | Рёбра только с одной смежной гранью |
| Isolated Verts | WARNING | Вершины без смежных рёбер |
| Duplicate Verts | BLOCKER | Совпадающие вершины в пределах одного связного шелла (0,01 мм) — касание разных шеллов намеренное и не флагается |
| Face Aspect Ratio | INFO | Отношение сторон квада выше порога (по умолчанию 6:1) |
| Triangles | INFO | Треугольники вне зон деформации/subdiv |
| Ngons | WARNING | Грани с более чем 4 вершинами |
| Poles | INFO | N-poles (3 ребра), E-poles (5+ рёбер) |
| Zero Area | BLOCKER | Вырожденные грани с почти нулевой площадью |
| Z-Fighting | BLOCKER | Копланарная пересекающаяся геометрия |
| Lamina | BLOCKER | Грани нулевой толщины, сложенные сами на себя |
| Zero Length Edges | BLOCKER | Рёбра почти нулевой длины (ниже 1e-8) |
| Starlike | WARNING | Незвездообразные грани: самопересекающийся контур или центроид не видит весь контур (паритет с Maya `isStarlike`) |
| Sharp Edges Not Hard | WARNING | Рёбра с двугранным углом ≥ 30°, НЕ помеченные sharp — флагаются только пропущенные |

### TRANSFORMS
| Проверка | Критичность | Описание |
|---|---|---|
| Non Applied Transform | BLOCKER | Не обнулённая ротация (нужен freeze transforms) |
| Scale | BLOCKER | Скейл не (1,1,1) |
| Origin at Zero | INFO | Пивот объекта не в мировом нуле |
| Modifier Stack | WARNING | Неприменённые модификаторы (исключается только Armature) |
| Uncentered Pivots | INFO | Пивот дальше 5% диагонали bbox от центра bbox |
| Parent Geometry | WARNING | Объект запарентован под другим меш-объектом |

### SYMMETRY
| Проверка | Критичность | Описание |
|---|---|---|
| Symmetry X / Y / Z | INFO | Зеркальный поиск вершин через KD-дерево |

### UV
| Проверка | Критичность | Описание |
|---|---|---|
| Single Set | WARNING | У меша должна быть ровно 1 UV-карта |
| Overlap | BLOCKER | Детект пересечений UV-островов |
| Micro Shell | WARNING | UV-острова меньше ~6px при 2048 |
| Texel Density | INFO | TD в px/cm с целевым значением и допуском |
| Stretch | WARNING | Искажение UV-углов (алгоритм ZenUV) |
| Padding | INFO | Отступы между шеллами и до границ тайла |
| UDIM Bounds | BLOCKER | UV-острова, пересекающие границы UDIM-тайлов |
| UV Material UDIM | BLOCKER | Разные материалы на одном UDIM-тайле |
| Missing UVs | WARNING | Грани без UV-развёртки (нет UV-слоя или все лупы в 0,0) |

### NAMING
| Проверка | Критичность | Описание |
|---|---|---|
| Obj Naming | WARNING | Имена объектов должны соответствовать политике нейминга |
| Col Naming | WARNING | Валидация имён коллекций |
| Mat Numbering | WARNING | Ловит суффиксы материалов `.001`, `.002` |
| Mesh Data Name | WARNING | Меш-датаблок не должен держать автонейм (`Mesh.101`) — переименование в один клик в `<object>_mesh`, суффикс настраивается |
| Duplicated Names | BLOCKER | Одно имя объекта используется несколькими объектами (коллизии linked-библиотек) |
| Trailing Numbers | WARNING | Имя объекта заканчивается цифрами (остатки в стиле `Cube.001`) |

### MATERIALS

| Missing Textures | BLOCKER | Подключённые файлы текстур должны существовать |

## Уровни критичности

| Уровень | Значение |
|---|---|
| 🔴 BLOCKER | Ассет невозможно сдать — обязательный фикс |
| 🟡 WARNING | Требуется решение артиста — нужна проверка |
| 🔵 INFO | Только к сведению — на статус не влияет |

## Возможности

- **Live Mode** — проверки перезапускаются автоматически при правках, без ручного перезапуска
- **Face Orientation** — встроенный оверлей нормалей Blender, тумблер из панели
- **Пресеты проверок** — нативный дропдаун; наборы проверок + правила нейминга сохраняются в файлы, удобно делиться с командой
- **Next Issue** — одна кнопка прыгает к следующему проблемному объекту и фреймит его
- **Copy Summary** — отчёт валидации в буфер обмена одним кликом
- **Health Strip** — цветные статусные точки по категориям в блоке счёта
- **Progress Bar** — сегментный прогресс-бар во время валидации Scene/Collection
- **GPU-оверлеи** — цветная заливка граней, обводка рёбер и маркеры вершин в 3D-вьюпорте
- **Оверлеи в UV Editor** — подсветка шеллов в Image Editor
- **Выделение в Edit Mode** — клик Sel выделяет проблемную геометрию
- **Coordinator Mode** — отфильтрованный вид только с BLOCKER + WARNING проверками
- **Экспорт отчётов** — форматы JSON, CSV, HTML
- **Pre-flight Export** — валидация FBX и USD перед экспортом
- **Чекпоинты** — сохранение и восстановление состояния валидации
- **Система игноров** — отключение отдельных проверок для конкретных объектов
- **Валидатор иерархии** — скан пайплайн-структуры (корни ассетов, функциональные слои, группы `_grp`, детект сирот) с древовидным видом; автоперескан в Live-режиме; фиксы в один клик (суффикс группы, перенумерация групп, подключение сирот, создание корня) и генератор скелета ассета; агрегированный вид правил; игнор per-node; вайтлист функциональных слоёв и суффикс групп настраиваются в Preferences. В **Coordinator Mode** находки эскалируют Asset Status — гейт иерархии относится к стадии приёмки, а не к WIP
- **Проверка юнитов сцены** — валидация METRIC / METERS / скейл 1.0
- **Журнал сессии + Debug Info** — диагностика аддона пишется в `%TEMP%/stukach.log`; одна кнопка копирует диагностический снапшот в буфер обмена
- **Подпись валидатора** — отчёты подписываются именем валидатора (Preferences → Validator)
- **Отчёты с учётом режима** — в режиме артиста копируется компактное саммари, в режиме координатора — формальный вердикт (READY / REVIEW / BLOCKED с секциями «что чинить первым»)

## Preferences

Доступ: Edit → Preferences → Extensions → STUKACH ⚙️

- **Colors** — цветовые свотчи оверлеев для каждой проверки
- **Offsets** — смещения оверлеев граней и точек
- **UV Padding** — пороги отступов шеллов и границ тайлов
- **UV Stretch** — порог искажения углов (радианы)
- **Texel Density** — размер текстуры, целевая TD, допуск
- **Face Aspect Ratio** — порог отношения сторон квада
